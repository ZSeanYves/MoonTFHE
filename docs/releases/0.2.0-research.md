# MoonTFHE 0.2.0-research

This release records the Boolean Core research baseline after the A0-A4
evidence and performance work.

## Included

- secure native entropy, fixed-point Gaussian fixtures, and portable provider
  failure semantics;
- typed Boolean facade, programmable anti-periodic LUTs, and an opaque
  evaluation context;
- RustFFT C ABI with reusable workspace, full-width Torus32 differential tests,
  fused blind-rotation entrypoint, and sanitizer/no-allocation coverage;
- schema-v3 interleaved benchmark evidence with stage metrics, measured
  external-product counts, gate PBS-count checks, and generated stage profiles.

## Explicit limits

- Native PBS/NAND remains about 4.2x the fixed tfhe-rs Boolean harness on the
  recorded runner; the 2x target is not met.
- Portable backends provide reference semantics and require a trusted host
  entropy provider for standard key generation.
- Parameter estimator output remains research evidence, not a security proof.
- No independent cryptographic or side-channel audit has been performed.
- Shortint, Integer, GPU, and C API compatibility are not included.

This tag must remain a research release until the performance, estimator, and
audit gates are independently satisfied.
